# Roblox Avatar Scripts

This project contains scripts to create and control an avatar in Roblox games. It includes scripts for controlling the avatar's actions, handling the avatar's movement, and managing the avatar's animations.

## Install

1. Download the scripts from the GitHub repository.
2. Open Roblox Studio.
3. Create a new place or open an existing one.
4. Insert a character model into the workspace.

## Use

1. Open the Scripts tab and create a new LocalScript.
2. Copy and paste the content of each script into the respective LocalScript.
3. Replace the animation IDs with your own animation IDs.
4. Run the game to see the avatar in action.
